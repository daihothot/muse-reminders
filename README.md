## 订阅地址

```
https://daihothot.github.io/muse-reminders/muse-reminders.ics
```

在 iPhone 中进入“设置 → Apps → 日历 → 日历账户 → 添加账户 → 其他 → 添加已订阅的日历”，粘贴上面的地址即可。不要下载后一次性导入；使用订阅地址才能收到后续更新。
